How the value is worked out

Implied value = TVL x category multiple x growth factor x age factor x chain factor. The category multiple is the median market-cap-to-TVL ratio of the snapshot's token-bearing protocols in the same category (the global median when a category has fewer than two), clamped to 0.02–3.0. Growth uses the 7-day TVL change, age uses the time since the protocol was first tracked, and chain count uses how many chains it runs on. Nothing here names a protocol by hand: the same program on a later snapshot would rank later launches on its own.

“Records no token” means the snapshot carries neither a CoinGecko id nor a symbol for the protocol. That is the snapshot's record, never a claim that it has none. An implied value is this radar's own claim from the snapshot's figures, never a promise that a token will launch or what it will be worth.
